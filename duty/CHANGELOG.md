# 당번표 변경 내역

## 2026-11-25 · 1단계 UI·UX 개편 (회원 화면)
- 회원 화면(`duty/index.html`)을 토스 스타일로 개편: 홈 / 당번표 / 교환 / 설정 하단 탭, Pretendard, 본문 16px 이상, 버튼 54px.
- 홈: 나의 다음 당번 카드(D-day), 받은 요청·바꿀 수 있는 당번 건수, 앞으로 내 당번.
- 당번표: 목록/달력 전환(선택 기억), 달 이동, 마감 표시.
- 교환: 교환 흐름 화면(당번 고르기 → 특정 회원 / 교환 가능한 회원 찾기 → 지금·바뀐 뒤 비교 → 요청). 요일·날짜 조건은 '찾기' 흐름 안에서만 선택.
- 교환 메뉴: 받은 요청(+공개 요청 수락) / 보낸 요청 / 교환 내역.
- 데이터·서버·관리자 화면은 변경 없음. 이전 화면 백업: git 태그 `duty-backup-20261125-before-ui-overhaul`.
- 제외(서버 변경 필요, 3단계에서 별도 안내 후 진행): '당번 확인했어요' 기능.

## 2026-11-25 · 카카오톡 공유
- 요청을 보낸 뒤 '카카오톡으로 보내기' 버튼, 보낸 요청의 '카카오톡으로 다시 알리기' 버튼 추가. 카카오 JavaScript SDK(2.7.4) 사용, 받는 분 카드에 '수락하러 가기' 버튼.
- 카카오 연결이 안 되면 휴대폰 공유 창 → 문구 복사 순서로 대신함. 서버·데이터 변경 없음.

## 2026-11-25 · 중복 요청 정리 (2단계)
- 수락·총무 수정 등으로 당번표가 바뀌면, 더는 성립하지 않는 대기 요청을 서버에서 '당번이 바뀌어 처리되지 않음'으로 자동 정리(`common.js` sweep). 정리에 실패해도 화면은 성립하는 요청만 보여 줌.
- 같은 당번으로 공개 요청을 올리면 기존 요청(개인·공개)이 취소되고, 개인 요청을 보내면 그 당번의 공개 요청이 취소됨. 화면에서 미리 안내.
- 데이터 구조 변경 없음(요청의 status 값만 사용).

## 2026-11-25 · 3단계 관리자 개선 (1차)
- 총무 화면 '자동 배정': 운영 요일(기본 화·수·목·토·일)·하루 인원(기본 2명)·휴관일·제외 회원을 정하고 가나다순으로 돌아가며 배정. 직전 달 마지막 당번 다음 사람부터 이어서 시작 가능. 미리보기 → 두 번 눌러 적용, 적용 전 당번표는 이 브라우저에 백업되어 '직전 당번표로 되돌리기' 가능.
- 총무 화면 '당번 확인 현황': 앞으로 2주 당번의 확인/미확인, 미확인 안내 문구 복사.
- 회원 홈: '확인했어요' 버튼(새 컬렉션 `acks`에 기록. 기존 데이터 변경 없음). ※ Firestore 규칙이 acks 쓰기를 막으면 저장 실패 안내가 뜸.
- 교환 요청 현황에 대기/성사/취소/만료 건수 요약 추가.
- 미적용: 총무 로그인·서버 규칙(점검 결과 보고 후 동의받아 진행).
