# 당번표 변경 내역

## 2026-11-25 · 당번표 탭 순서
- 총무 화면 당번표 탭에서 '단톡방 당번 안내'와 '당번표 달력'의 순서를 바꿈: 달력 → 카톡용 이미지 만들기 → 단톡방 당번 안내.

## 2026-11-25 · 총무 화면 달 넘기기 버튼 고정
- 총무 화면의 '이전 · N월 · 다음' 줄이 스크롤해도 화면 맨 위에 붙어 있게 함(달력 아래까지 내려도 바로 다음 달로 넘김). '당번 입력하기'·마감 버튼 줄은 위에 그대로 두어 가리지 않게 분리.

## 2026-11-25 · 카톡용 당번표 이미지 새 디자인 + 카톡으로 보내기
- 이미지를 토스 스타일로 새로 그림: 제목 '12월 당번표' + 오른쪽 'NN/NN HH시MM분 기준', 회색 둥근 날짜 칸, 토요일 파랑·일요일 빨강. 아래 '변경 내역'과 앱 주소 문구는 없앰.
- 교환으로 바뀐 사람의 '이름만' 노란색으로 표시(칸 전체가 아님). 안내: '노란 이름은 교환으로 바뀐 당번이에요'.
- 총무 화면에 '카톡으로 보내기' 추가: 이미지를 카카오에 올려 카드(이미지 + 버튼 '교환 요청 바로가기' / '당번표 열기')로 보냄. 카톡 연결이 안 되면 복사·저장·공유로 대신함. 카드 제목은 비워 보내고, 카카오가 거부하면 'N월 당번표'로 다시 보냄.

## 2026-11-25 · 카톡용 당번표 이미지
- 이미지 아래 '변경 내역' 목록을 넣지 않도록 함('노란 칸은 교환으로 바뀐 날이에요' 안내는 유지).

## 2026-11-25 · 토요일 파란색
- 달력에서 토요일 요일·날짜 숫자를 파란색으로(일요일은 빨간색 그대로). 회원 앱·총무 화면 달력, 교환 날짜 고르기, 이미지 인식 목록에 적용.

## 2026-11-25 · 총무 화면 달력 이름 잘림
- 폰에서 총무 당번표 달력의 이름 입력 칸이 3글자 이름 끝이 잘려 보이던 문제: 칸 글자를 11px로 줄이고 자간·여백·칸 간격을 좁혀 3글자 이름이 칸에 들어가게 함(글자 크기를 키워 둔 폰도 고려).

## 2026-11-25 · 이름 검색 모양
- 회원 앱 이름 선택·총무 명단 검색에서 '이름 검색' 제목을 없애고, 돋보기 아이콘을 검색 칸 안 왼쪽에 넣음(칸 설명은 그대로).

## 2026-11-25 · 명단 탭이 0명으로 보이던 문제
- 명단 탭을 눌러도 이전에 그려 둔(데이터가 오기 전의) 화면이 그대로 남아 '0명 · 아직 명단을 저장하지 않았어요'로 보이던 표시 오류를 고침. 탭을 열 때마다 명단을 새로 그림. 저장된 명단 데이터는 영향 없음.

## 2026-11-25 · 게임현황판 명단 그대로 적용
- 명단 탭 '게임현황판에서 명단 가져오기'에 '게임현황판 명단 그대로로 바꾸기' 추가(두 번 눌러 확인). 앱 명단을 게임현황판 활동 회원 98명으로 교체하고, 쉼 표시는 남아 있는 회원만 유지. 당번표 이름은 건드리지 않음.

## 2026-11-25 · 공지 수정·삭제
- 총무 화면 공지 탭의 '올린 공지'에 '수정'(제목·내용 고쳐 저장)과 '삭제'(두 번 눌러 확인, 되돌릴 수 없음) 추가. 기존 '내리기'(숨김)는 그대로.
- 서버: 삭제는 Firestore 규칙의 `notices` 삭제 허용이 필요함(허용 전에는 삭제 시 안내 문구가 나오고 '내리기'로 대체). 수정은 기존 규칙으로 동작.

## 2026-11-25 · 총무 화면 하단 메뉴가 안 나오던 문제
- 원인: 폰이 예전 `duty-core.js`를 캐시에 가진 채 새 화면을 열어, 새 함수가 없어 그리기가 중간에 멈춤(메뉴는 맨 마지막에 그려져 빠짐).
- 고침: 스크립트 주소에 버전 표시를 붙여 새로 올릴 때마다 새 파일을 받게 함. 총무 화면은 한 부분이 오류여도 나머지(메뉴 포함)를 계속 그림.

## 2026-11-25 · 당일 교환 허용, 설정 안내 정리
- 당번 당일에도 교환 요청·수락 가능(당번일이 지난 다음 날부터 만료).
- 회원 설정의 안내 글은 '요청을 보낸 뒤에는 카톡으로도 한 번 알려 주세요.' 한 줄만 남김.
- 회원 홈 맨 위 '좌동클럽 당번' 작은 글자 제거.

## 2026-11-25 · 초대 링크 + 초성 검색
- 총무 도구 탭 '회원 초대 링크': 복사한 링크(`…/duty/#p=…`)로 들어오면 암호 입력 없이 열리고, 주소의 암호 부분은 바로 지워짐. 링크를 아는 사람은 누구나 들어올 수 있으니 단톡방에만 공유.
- 이름 검색에서 초성 검색(ㄱㅎㄹ, 김ㅎㄹ 등) 지원: 회원 이름 선택 화면, 총무 명단 탭(검색 칸 새로 추가). 돋보기 아이콘 옆에 '이름 검색' 글자 표시.

## 2026-11-25 · 단톡방 당번 안내 카드 다듬기
- 파란 띠를 얇게(5:1) 하고, 띠에 '11/25(수) 당번 안내'처럼 날짜를 넣음(보낼 때마다 그려서 카카오에 올림, 실패하면 날짜 없는 기본 띠).
- 제목 '김혜란 · 고진숙 님, 오늘 당번이에요', 설명 '바닥 청소 및 전원 관리(냉·난방기, 조명) 신경 써 주세요.'

## 2026-11-25 · 카카오톡 보내기 디자인 개선(카드형)
- 교환 요청·공개 요청·오늘/내일 당번 안내를 카톡 '피드 카드'로 보냄: 위에 토스 파란 배너(`kakao-swap.png`, `kakao-duty.png`), 굵은 제목 + 설명 한 줄 + 버튼.
- 제목 예: '김재용님이 12/2(수) 당번 교환을 요청했어요', 설명 예: '수, 목, 토 중 11/26 외 4일 가능'. 당번 안내 버튼은 두 개: 요청은 '요청 확인하기'·'당번표 열기'(바로 수락되는 것으로 오해하지 않게 '수락' 문구를 쓰지 않음), 당번 안내는 '당번표 열기'·'교환 요청하기'.
- 카톡 연결이 안 되면 이전처럼 공유 창/문구 복사로 대신함.

## 2026-11-25 · 회원 홈 다듬기
- 홈 상단 파란 카드의 '나의 다음 당번' 문구 제거.
- 홈 공지 카드: '공지 ·' 글자 대신 벨 아이콘(새 공지는 '새' 표시).
- '받은 교환 요청'·'바꿀 수 있는 당번'은 각각 한 줄(이름 왼쪽, 건수 오른쪽)로.

## 2026-11-25 · 총무 달력 이름 잘림 수정
- 폰 화면에서 총무 달력 칸의 이름이 잘리던 문제: 칸 여백을 줄이고 글자를 조금 줄였으며, 4글자 이상 이름은 두 줄로 나뉨.

## 2026-11-25 · 총무 도구: 당번표 초기화
- 도구 탭 '당번표 초기화': 고른 달의 당번을 모두 비움(두 번 눌러 확인). 비우기 전 당번표는 이 기기에 백업되고 '직전 당번표로 되돌리기'로 복구. 달 문서 자체는 지우지 않고 당번만 빈 상태로 저장.

## 2026-11-25 · 총무 암호 기억하기
- 총무 전용 암호를 한 번 맞게 입력하면 그 기기에서는 다음부터 묻지 않음(암호를 바꾸면 다시 묻는다).

## 2026-11-25 · 회원 홈 '내 당번 캘린더에 넣기' 제거
- 폰마다 .ics 파일이 열리지 않는 경우가 있어 기능(파일 받기, 구글 캘린더 링크)을 모두 뺌. 단톡방 당번 안내(총무)는 그대로.

## 2026-11-25 · 총무 지정 + 총무 전용 암호 (회원 앱 한 주소로)
- 총무 화면 명단 탭: 회원별 '총무 지정/해제', '총무 전용 암호 정하기·바꾸기'(6자 이상). 암호 원문은 저장하지 않고 느린 해시(PBKDF2-SHA256 15만 회)와 무작위 값만 저장.
- 회원 앱: 총무로 지정된 회원의 설정에 '총무 화면 열기' → 총무 전용 암호 확인 후 앱 안에서 총무 화면이 열림(`admin.html?embed=1`을 화면 안에 불러옴). 일반 회원에게는 보이지 않음.
- 총무 화면 주소(`admin.html`)를 직접 열어도 클럽 암호 뒤에 총무 전용 암호를 묻는다(암호가 정해진 뒤부터).
- 한계: 로그인이 없는 구조라 코드 수준의 '가벼운 보호'임(이름 선택과 같은 신뢰 방식). 실제 권한 분리는 로그인 도입이 필요.
- 서버 변경: 새 저장 위치 `meta/admin`(Firestore 규칙 추가 필요). 규칙 게시 전에는 암호·총무 지정 저장이 되지 않고, 총무 화면은 이전처럼 열림.

## 2026-11-25 · 당번 알림 (① 총무 안내 + ② 내 캘린더)
- 총무 당번표 화면 맨 위에 '단톡방 당번 안내' 카드: 오늘·내일 당번(없으면 가까운 다음 당번)을 보여 주고 '카톡으로 안내'(카톡 공유 창에서 단톡방 선택) 또는 '문구 복사'.
- 회원 홈 '앞으로 내 당번' 아래에 '내 당번 캘린더에 넣기': 앞으로 내 당번을 .ics 파일로 받아 캘린더에 추가, 전날 오전 9시·당일 오전 9시 알림. 같은 날짜는 다시 받으면 갱신(고정 ID).
- 서버·데이터 변경 없음. 완전 자동 단톡방 발송은 카카오 정책상 제외.

## 2026-11-25 · 당번 입력하기
- 총무 앱 '새 달 만들기' → '당번 입력하기'로 변경. 달을 고른 뒤 두 가지 방식 중 선택: ① 개별로 입력(새 달이면 만들고 입력 모드로 전환) ② 당번표 이미지로 입력(달력 캡처를 올려 글자 읽기). 이미지 올리기 칸은 도구 탭에서 이 화면으로 옮김.

## 2026-11-25 · 총무 앱 보완
- '이 달 교환 마감' 버튼 삭제(이미 마감된 달이 있을 때만 '풀기' 버튼이 나타남).
- 총무 당번표 화면에서 회원 이름을 누르면 선택 카드가 뜨고, '이 회원 대신 교환 요청 보내기'로 회원용 교환 화면과 똑같은 흐름(특정 회원 달력 선택 / 교환 가능한 회원 찾기 + 요일·날짜·요일+날짜·빼고 조건)을 진행. 선택한 회원 이름으로 요청이 올라가고 카톡 문구도 만들어 줌. 기존의 '바로 교환'(두 번째 사람 누르기)도 그대로.
- 교환 탭의 선택식 '회원 대신 요청' 카드는 위 흐름으로 대체해 삭제.
- 명단 탭에 '게임현황판에서 명단 가져오기'(`duty/board-members.json`, 게임현황판 회원 98명): 비교 → 오타로 보이는 이름 바꾸기 제안(예: 김동을→김동율) → 새 회원 추가.

## 2026-11-25 · 총무용 앱 개편 + 명단·공지·대신 요청
- 총무용 화면(`admin.html`)을 회원용과 같은 토스 스타일로 개편: 하단 탭 5개(당번표 / 교환 / 명단 / 공지 / 도구). 기존 기능(교환·입력, 이미지 올리기, 자동 배정, 되돌리기, 마감 등)은 그대로.
- 명단 탭(신규): 회원 추가, 이름 변경(모든 달 당번표 이름도 함께 변경), 쉼(자동 배정에서 제외), 명단에서 빼기(두 번 눌러 확인). 명단은 회원 앱 이름 선택 화면에 사용됨. 저장 전에는 당번표 이름으로 만든 목록을 보여 주고 '이 명단으로 확정'으로 저장.
- 교환 탭에 '회원 대신 교환 요청 보내기'(총무가 회원·당번·상대를 골라 그 회원 이름으로 요청, 상대용 카톡 문구 복사).
- 공지 탭(신규): 제목·내용·고정 게시/내리기. 회원 앱에는 '공지' 탭과 홈 카드, 새 글 배지 추가.
- 총무 화면의 '공지 문구 복사'와 '카톡 공지 미리보기'는 삭제(카톡용 이미지 만들기는 유지).
- 서버 변경: 새 저장 위치 2곳(`meta/roster`, `notices`). Firestore 규칙에 두 항목 추가가 필요함(게시 전에는 명단/공지 저장이 되지 않고 기존 기능은 그대로 동작).

## 2026-11-25 · 화면 개선 4가지
- 당번표 탭: '달력으로 보기'가 먼저, '목록으로 보기'가 다음. 기본 화면은 달력(보기 선택 저장 키를 새로 만들어 모두 달력으로 시작).
- 달력 칸에 날짜와 함께 당번 이름 표시(내 당번은 파란색).
- 교환 '누구와 바꿀까요?'에 달력 보기 추가(기본). 날짜를 누르면 그날 당번 이름 버튼이 나오고, 바꿀 수 없는 날은 흐리게. 목록 보기도 그대로 선택 가능.
- 교환 가능한 회원 찾기 조건에 '요일+날짜' 추가: 고른 요일이면서 고른 날짜인 날만 해당(예: 화·목 중 12/8, 12/15). 요일을 빼면 그 요일 날짜는 자동으로 빠짐. 관리자 요청 목록에도 "화·목요일 중 12/8, 12/15 가능"으로 표시.
