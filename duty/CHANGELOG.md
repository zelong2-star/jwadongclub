# 당번표 변경 내역

## 2026-11-25 · 1단계 UI·UX 개편 (회원 화면)
- 회원 화면(`duty/index.html`)을 토스 스타일로 개편: 홈 / 당번표 / 교환 / 설정 하단 탭, Pretendard, 본문 16px 이상, 버튼 54px.
- 홈: 나의 다음 당번 카드(D-day), 받은 요청·바꿀 수 있는 당번 건수, 앞으로 내 당번.
- 당번표: 목록/달력 전환(선택 기억), 달 이동, 마감 표시.
- 교환: 교환 흐름 화면(당번 고르기 → 특정 회원 / 교환 가능한 회원 찾기 → 지금·바뀐 뒤 비교 → 요청). 요일·날짜 조건은 '찾기' 흐름 안에서만 선택.
- 교환 메뉴: 받은 요청(+공개 요청 수락) / 보낸 요청 / 교환 내역.
- 데이터·서버·관리자 화면은 변경 없음. 이전 화면 백업: git 태그 `duty-backup-20261125-before-ui-overhaul`.
- 제외(서버 변경 필요, 3단계에서 별도 안내 후 진행): '당번 확인했어요' 기능.
